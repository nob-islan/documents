# AWS CLI インストール

[公式ドキュメント](https://docs.aws.amazon.com/ja_jp/cli/latest/userguide/getting-started-install.html)を見ればいけるはず。

- ツールのダウンロード

```
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
```

- 展開（`unzip`コマンドが必要）

```
unzip awscliv2.zip
```

- インストール

```
sudo ./aws/install
```
