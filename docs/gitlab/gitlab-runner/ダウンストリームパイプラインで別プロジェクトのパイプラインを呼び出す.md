# ダウンストリームパイプラインで別プロジェクトのパイプラインを呼び出す

cf. https://docs.gitlab.com/ci/pipelines/downstream_pipelines/

下記要領で`nob/example-project`のパイプラインを呼び出すことができます:

```yaml
trigger_another_pipeline:
  stage: trigger
  trigger:
    project: nob/example-project
    branch: main
    strategy: mirror
```

呼び出される側の`rules`で`$CI_PIPELINE_SOURCE == "pipeline"`が許可されている必要があるので注意してください。
