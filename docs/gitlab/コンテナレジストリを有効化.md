# コンテナレジストリを有効化

GitLab上でコンテナレジストリを有効化します。

cf.

- https://docs.gitlab.com/user/packages/container_registry/
- https://docs.gitlab.com/administration/packages/container_registry/

## 設定

下記設定を追加してGitLabを再起動します:

```yaml
registry_external_url "{registry向けドメイン}"
```

GitLabのURL http://gitlab.example.com に対し、http://registry.gitlab.example.com などのように設定します。

## 使い方

- 対象プロジェクトの**Deploy**から**Container registry**を選択することでコンテナイメージ管理画面が表示されます。
