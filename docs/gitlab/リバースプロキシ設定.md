# リバースプロキシ設定

リバースプロキシ越しにGitLabにSSL通信を行う際の設定です。

cf. https://docs.gitlab.com/omnibus/settings/ssl/?utm_source=chatgpt.com#configure-a-reverse-proxy-or-load-balancer-ssl-termination

## 設定

- GitLabに下記設定を付与します:

```rb
gitlab_rails['nginx']['listen_port'] = 80
gitlab_rails['nginx']['listen_https'] = false
```

- docker-composeに記載する場合は下記です:

```yaml
nginx['listen_port'] = 80
nginx['listen_https'] = false
```
