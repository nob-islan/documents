# バリデーション実装

リクエストパラメータのバリデーションを実装します。

cf.

- https://echo.labstack.com/guide/request/#validate-data
- https://pkg.go.dev/github.com/go-playground/validator/v10

## 事前準備

- `validator`パッケージをインストールします:

```shell
go get github.com/go-playground/validator/v10
```

## 実装

### `internal/validation`

バリデータを実装します。`NewValidationError`にてバリデーションエラーからエラーメッセージを作成し`error`型として返します。

- `validator.go`

```go
package validation

import (
	"fmt"

	"github.com/go-playground/validator/v10"
)

type CustomValidator struct {
	validator *validator.Validate
}

func NewCustomValidator() *CustomValidator {
	return &CustomValidator{validator: validator.New()}
}

func (cv *CustomValidator) Validate(i any) error {
	if err := cv.validator.Struct(i); err != nil {
		return err
	}
	return nil
}

type ValidationError struct {
	Messages []string `json:"messages" example:"invalid request"`
}

func (e ValidationError) Error() string {
	return fmt.Sprintf("%v", e.Messages)
}

func NewValidationError(err error) ValidationError {
	validationErrors, ok := err.(validator.ValidationErrors)
	if !ok {
		return ValidationError{[]string{"unknown error"}}
	}
	var errorMessages []string
	for _, e := range validationErrors {
		errorMessages = append(
			errorMessages,
			fmt.Sprintf("invalid parameter. field: %s, tag: %s, value: %v",
				e.Field(),
				e.Tag(),
				e.Value(),
			),
		)
	}

	return ValidationError{Messages: errorMessages}
}
```

### `internal/bootstrap/`

- `server.go`

バリデータを初期化するため下記を宣言します:

```go
	e := echo.New()
	e.Validator = validation.NewCustomValidator()
```

### `internal/presentation/handler/model`

`validate`タグを用いてバリデーションを宣言し、`c.Validate`で値の検証を行います。

- `user_model.go`

```go
type LoginReq struct {
	Name     string `json:"name" example:"nob"`                            // ユーザ名
	Password string `json:"password" example:"passwd" validate:"required"` // パスワード
}

func NewLoginReq(c *echo.Context) (LoginReq, error) {

	req := new(LoginReq)
	if err := c.Bind(req); err != nil {
		return LoginReq{}, errors.New("invalid request")
	}
	if err := c.Validate(req); err != nil {
		return LoginReq{}, validation.NewValidationError(err)
	}

	return *req, nil
}
```

### `internal/presentation/handler`

`NewLoginReq`からバリデーションエラーが返ってきた場合、そのエラーをAPIレスポンスとして返します。

- `user_handler.go`

```go
	req, err := model.NewLoginReq(c)
	if err != nil {
		if err, ok := err.(validation.ValidationError); ok {
			return c.JSON(
				http.StatusBadRequest,
				err,
			)
		}
		return c.JSON(
			http.StatusBadRequest,
			echo.NewHTTPError(
				http.StatusBadRequest,
				"bad request",
			),
		)
	}
```
