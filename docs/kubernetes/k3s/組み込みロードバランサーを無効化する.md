# 組み込みロードバランサーを無効化する

K3sはデフォルトで[klipper](https://github.com/k3s-io/klipper-lb)というロードバランサーが組み込まれています。
Metallbなどの異なるロードバランサーを使うためにこれを無効化する手順を記載します。

## 手順

cf. https://docs.k3s.io/networking/networking-services#disabling-servicelb

下記コマンドでklipperを無効化できます:

```shell
curl -sfL https://get.k3s.io | sh -s - server --disable=servicelb
```
