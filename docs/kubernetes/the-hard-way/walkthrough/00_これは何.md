# 0. これは何

[Kubernetes The Hard Way](https://github.com/kelseyhightower/kubernetes-the-hard-way)を原作とする、Kubernetes自体の原理および動作について理解するためのドキュメントです。

通常、Kubernetesの構築には[kubeadm](https://kubernetes.io/ja/docs/reference/setup-tools/kubeadm/)や各種クラウドサービスが提供するツールを用いますが、本稿ではそれらを用いずに手動でクラスタを構築します。
