# 単体テスト作成

cf.

- https://vitest.dev/guide/
- https://testing-library.com/docs/svelte-testing-library/setup/#vitest

## 事前準備

- [Vitest](https://vitest.dev/)をインストールします:

```shell
npm install -D vitest
```

- `package.json`に`test`スクリプトを追加します:

```json
{
  "scripts": {
    "test": "vitest"
  }
}
```

- [Testing Library](https://testing-library.com/)向けのパッケージをインストールします:

```shell
npm install --save-dev @testing-library/react @testing-library/user-event
```

- Vites向けのパッケージをインストールします:

```shell
npm install --save-dev \
  @testing-library/svelte \
  @testing-library/jest-dom \
  @sveltejs/vite-plugin-svelte \
  vitest \
  jsdom
```

- `vitest-setup.js`を下記内容で作成します:

```js
import "@testing-library/jest-dom/vitest";
```

- `vite.config.js`を下記内容で更新します:

```js
import { svelte } from "@sveltejs/vite-plugin-svelte";
import { svelteTesting } from "@testing-library/svelte/vite";
import { defineConfig } from "vitest/config";

export default defineConfig({
  plugins: [svelte(), svelteTesting()],
  test: {
    environment: "jsdom",
    setupFiles: ["./vitest-setup.js"],
  },
});
```

## テスト実行

- 下記コマンドでプロジェクト内のテストを一括実行します:

```shell
npm run test
```
